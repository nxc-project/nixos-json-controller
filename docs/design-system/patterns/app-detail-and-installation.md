# アプリ詳細・インストール

詳細画面は、検索結果から選んだパッケージの内容を理解し、導入判断を行う場所です。

## 詳細情報の構成

- 最上部に「アプリを探す」など一覧へ戻る操作を置きます。
- アプリのアイコン・カテゴリ・タグ・名前を先に示します。
- バージョンや説明文は名前の直下に配置します。
- インストール操作は、対象パッケージが分かる領域に配置します。
- パッケージ ID は省略せず表示し、コピーや選択ができるようにします。
- ホームページなど外部リンクは外部サイトへ移動することを分かる形にします。

## インストール状態と導線

インストール操作は画面内で明確な primary action とします。現在の状態が確定していない場合は操作を無効化し、確認中・確認失敗を表示します。

処理中はボタンを disabled にし、重複操作を避けます。認証が必要な場合は対象アプリ名と目的を提示します。操作完了後は、バックエンドの確認結果に基づいて成功・未確認・失敗を表示します。

## 状態の継続性

一覧から詳細へ進み、戻った際に検索語やスクロール位置を不必要に失わないようにします。別のパッケージへ遷移した場合は、前のパッケージの状態やエラーが混ざらないようにします。

## エラーと例外

- パッケージが見つからない場合は、一覧へ戻る導線を示します。
- 詳細情報を取得できない場合は、ユーザー向けの説明と技術的詳細を分けます。
- インストール状態の取得に失敗しても、未インストールと断定しません。
- 外部ホームページがない場合は、空のリンク領域を作りません。
