# Design Patterns

デザインパターンは、共通コンポーネントを特定の画面・タスクでどう組み合わせるかを定義します。見た目だけでなく、情報の順序・状態遷移・エラー・戻り方を含みます。

## パターン一覧

| パターン | ドキュメント | 対象 |
| --- | --- | --- |
| アプリ発見・検索 | [app-discovery.md](app-discovery.md) | 検索前、おすすめ、検索結果、追加読み込み |
| アプリ詳細・インストール | [app-detail-and-installation.md](app-detail-and-installation.md) | 詳細情報、状態確認、インストール・認証 |

## パターンを追加する基準

複数画面で再利用する情報構造や操作フローがある場合に追加します。単一ページ内の一時的な配置変更までパターン化せず、別画面でも同じ判断を再利用できる粒度にします。

パターンの変更時は、影響するコンポーネント、空・読み込み・エラー状態、キーボード操作、戻る操作を合わせて確認します。
