# 基本要素（Foundations）

色・文字・余白・形・奥行きなど、複数の画面とコンポーネントで共有する視覚的な基礎を定義します。値の一覧と CSS 変数との対応は [design-tokens.md](design-tokens.md) を参照してください。

## 色

### 役割で選ぶ

- Primary: 主要アクション、リンク、選択、フォーカス
- Background: ページの基底面
- Card: コンテンツを載せる面
- Foreground: 主要テキスト
- Muted: 補助テキストや静かな面
- Secondary / Accent: 補助的な操作・選択面
- Border / Input: 区切りと入力部品
- Destructive: エラーや破壊的操作

色の役割をまたいで流用しません。例えば、カテゴリの識別色を主ボタンへ流用したり、destructive を通常の未インストール状態に使ったりしません。

### コントラストと状態

本文と背景は WCAG 2.2 AA の通常テキスト基準 4.5:1 を目安にし、大きな文字は 3:1 を目安にします。アイコンや境界など UI を識別するための色も背景とのコントラストを確認します。色の差だけに状態を任せず、ラベル・形・アイコンを併用します。

現行の CSS にはライト・ダーク双方の semantic color variables があります。ユーザー向けのテーマ切り替え UI が用意されていることまではこの初期調査で確認できていないため、ダークテーマの提供範囲や切り替え方法は別途検証が必要です。

## タイポグラフィ

Geist Variable を基本書体とします。日本語グリフの表示は実行環境のフォールバックを含めて確認します。

- Display / Heading: 画面の目的と階層を示す。見出しを大きくしすぎず、本文との関係を保つ。
- Body: 説明・本文は 16px を基本とする。
- Body Small: 補助情報・カテゴリ・メタデータは 14px を基本とする。
- Label: ボタンや状態ラベルは短く、操作や状態を端的に表す。
- Technical: パッケージ ID、コマンド、バージョンは、折り返しやコピー可能性を考慮して表示する。

12px 未満の文字は原則使いません。既存画面に小さなバッジなどの例外がある場合は、視認性と必要性を見直す対象として扱います。

## 余白とレイアウト

Tailwind CSS の標準 spacing scale を基準にし、4px の倍数で余白を組み立てます。余白を個別の値で増やし続けず、近い意味の領域は同じ段階を使います。

- ページ内のセクション間は、カード内部の要素間より大きな余白を取る。
- 見出しと説明文は近づけ、次の操作・コンテンツとは十分に離す。
- 一覧の繰り返し要素は揃ったグリッド・行高・間隔を使う。
- 幅が狭くなったときは、情報を隠す前に折り返しや縦積みを検討する。
- 横スクロールは、ランキングなど順序のある横並びコンテンツに限定する。

現行画面は Tailwind の spacing utility を直接使用しています。デザイントークン名を CSS 変数として全量定義しているわけではありません。

## 角丸と形状

frontend/src/index.css の --radius は 0.75rem（通常 16px root font-size 時に 12px）です。Tailwind theme の rounded 系はこの値から段階的に導出されます。

- 小さな入力・ボタン: rounded-lg 相当
- カード: rounded-xl 相当
- 大きなアイコンタイル: rounded-2xl 相当
- バッジ・状態チップ: rounded-full
- モーダル・大きなパネル: 内容と階層に応じて rounded-xl〜2xl

特定の画面だけに新しい角丸値を作る場合は、再利用する必要があるか先に検討します。

## 奥行き・境界・影

カードの境界は border または ring を基本とし、影は面を背景からわずかに分離するために使います。カードの種類ごとに影を増やさず、主役となる featured card や overlay など、階層を強める必要がある場面に限定します。

- 通常のカード: 薄い境界・ring、影はなし〜弱め
- Featured card: 情報の優先順位を示す場合に限り、控えめな shadow
- Popover / dialog: 背景との重なりを明確にする
- Hover: 境界・背景・影のいずれか一つか二つに絞る

## アイコンとモーション

アイコンは Lucide React を基本とし、同じ操作・状態には同じアイコンを使います。アイコンのみのボタンには aria-label と tooltip を用意します。パッケージアイコンは AppStream / アイコンテーマなどのアセットであり、装飾アイコンとは意味を分けます。

アニメーションは状態変化の理解を助けるためにだけ使います。処理中の spinner、カルーセル移動、控えめな hover を基本にし、prefers-reduced-motion が有効な場合は不要な移動を止めます。
