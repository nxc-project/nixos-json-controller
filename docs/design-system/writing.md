# ライティングガイド

NXC LOUNGE の UI 文言は、日本語を基本に、利用者が次に行う操作と現在の状態を短く正確に伝えます。翻訳調や過度な親しみ表現よりも、理解しやすさと技術的な正確さを優先します。

## 基本ルール

- 操作ラベルは動詞を使い、実行されることを具体的に示します（例:「検索」「インストール」「再試行」「キャンセル」）。
- 状態ラベルは現在の状態を表します（例:「インストール済み」「確認中」「処理中」）。
- 見出しは画面・領域の目的を示し、説明文は見出しを繰り返しません。
- 一文に複数の操作や条件を詰め込まず、必要に応じて分けます。
- 用語・表記は同じ画面・同じ機能で揃えます。

## 技術用語と識別子

Nixpkgs、NixOS、Nix、Flake、AppStream などの固有名詞は正しい表記を維持します。package attribute やパッケージ ID は勝手に翻訳・短縮せず、必要に応じて等幅フォントで表示します。

利用者向けの説明では専門語だけを置かず、何を意味するか補足します。ただし、正確性のために必要な技術用語は削除しません。

## 状態・エラー文言

状態やエラーは次の順番で伝えます。

1. 現在何が起きているか
2. 利用者に影響すること
3. 必要な場合、次に取れる行動

「失敗しました」だけで終わらず、対象や再試行の可否を示します。技術的詳細を表示する場合は、利用者向けの説明と混在させず、コピー・確認できる形にします。

インストール操作では、実行中・確認中・認証待ち・成功・未確認・失敗を混同しません。バックエンドが成功を返していない段階で「インストール済み」と表示しないようにします。

## 統計・外部情報

外部統計を表示する場合は、出典・対象範囲・対象期間を明示します。指標がどの環境の人気度なのかを説明し、NixOS の使用率と誤認される見せ方を避けます。

## 表記の統一

- UI 本文は日本語を基本とします。
- 外部サービス名・技術名・パッケージ名は公式表記を尊重します。
- 数字・単位・日付の形式は同じ情報種別で揃えます。
- 文末の句点は説明文では使い、短いボタンラベルや状態バッジには使いません。
- 用語を追加・変更した場合は、関連画面とこのガイドを同時に見直します。
